## Notas técnicas del render (reproducibilidad)

- VHS 0.10.0 (el 0.11 requiere ttyd ≥1.7.2; ambos lo necesitan — 0.10 lo verifica).
- Sintaxis 0.10: `Set Shell/FontSize/Width/Height/Theme "GruvboxDark"` (sin espacio),
  `Type "cmd" Sleep 300ms  Enter` en una línea; `Set WorkingDirectory` no existe.
- `Output` es relativo al CWD donde se corre `vhs`.
- **Prompt limpio:** con el env real, ttyd hereda `SHELL=/usr/bin/zsh` (p10k) y el
  prompt del host se vuelca en la captura. La receta que funciona:
  `env -i HOME="$HOME" SHELL=/bin/bash TERM=xterm-256color PATH="…ttyd…:$HOME/.local/bin:…" vhs tape`
  (VHS ejecuta `bash --noprofile --norc --login` con prompt `>` propio).
  Con `env -i` hay que mantener `HOME` real para que `~/.phoson/config.toml`
  (provider) siga resolviéndose.
- El input de VHS viaja por go-rod (Chromium headless) → requiere `ttyd` real en
  PATH; un wrapper no-binario no sirve (VHS habla HTTP con ttyd).
